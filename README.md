Lottery Wheel
เว็บแอปที่สุ่มผู้โชคดีจากรายการที่กรอกไว้ ทำเพื่อทดลอง

Features on this project
1. เพิ่ม ลบ จัดการรายการ
2. หมุนวงล้อสุ่มรายชื่อหรือเลข
3. เรียงลำดับและสลับลำดับรายการ
4. Undo และบันทึกข้อมูลอัตโนมัติ
5. ส่งออก นำเข้ารายการ
6. แสดงผลลัพธ์และประวัติล่าสุด

Run
1. เปิด index.html ใน browser
2. หรือรันด้วย Local server

Project Structure
1. index.html
2. main.js
3. style.css
4. sounds

Notes
แอปนี้เป็น frontend-only
ข้อมูลจะถูกบันทึกอยู่ใน LocalStorage ของ Browser
